    # 📖 Project Overview

    KAVACH is an AI-powered crop protection system designed to reduce crop damage caused by stray and grazing animals using computer vision and non-invasive deterrent mechanisms.

    ## ✨ Key Features

    - 🤖 YOLOv8 real-time animal detection
    - 📷 Live camera monitoring
    - 🚨 Smart alert generation
    - 🔦 Laser deterrent
    - 🔊 Speaker deterrent
    - 💧 High-pressure water sprinkler
    - 📱 Flutter farmer application
    - 🌍 English, Hindi and Gujarati support

    # 🔄 AI Workflow

    1. Capture camera frame.
    2. Detect animal with YOLOv8.
    3. Classify animal.
    4. Choose deterrent based on priority.
    5. Activate laser/speaker/sprinkler.
    6. Send alert.
    7. Display status in Flutter app.
